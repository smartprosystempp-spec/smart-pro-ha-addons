# Smart Pro Remote Support - Προσωρινή Συνεδρία

Πειραματική βάση για μελλοντική εφάπαξ απομακρυσμένη υποστήριξη απευθείας από Home Assistant OS.

> **Δεν είναι ακόμη λειτουργική έκδοση remote access.**

Η έκδοση 0.1.0 υπάρχει ώστε να κλειδώσουμε με ασφάλεια τη δομή, την παρουσίαση και τη συμπεριφορά εκκίνησης πριν προστεθεί πραγματικός agent/session μηχανισμός.
