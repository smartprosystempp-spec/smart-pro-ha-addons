# Managed Support 2.5.0 — QA checkpoint

1. Η εγκατάσταση πρέπει να είναι ήδη paired και ACTIVE.
2. Η support session πρέπει να είναι ACCEPTED.
3. Ο διαχειριστής πατά «Έγκριση έναρξης 60″».
4. Ο πελάτης βλέπει «Έτοιμη για έναρξη» και πατά «Έναρξη συνεδρίας».
5. Στο MeshCentral αναμένεται το managed node να γίνει online προσωρινά.
6. Η δοκιμή σταματά αυτόματα <=60s ή νωρίτερα αν τερματιστεί η συνεδρία.
7. Μετά το τέλος δεν πρέπει να υπάρχει τοπικό `meshagent`, `.msh` ή service persistence.
