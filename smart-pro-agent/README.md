# Smart Pro System - Remote Support 2.2.0

Managed Secure Settings Delivery QA για μόνιμες εγκαταστάσεις Smart Pro System.

Η 2.2.0 διατηρεί pairing, ασφαλή τοπική ταυτότητα, heartbeat, revoke/re-pair και τον ασφαλή έλεγχο προετοιμασίας της 2.1.0.

## Νέο στην 2.2.0

Το κουμπί **«Έλεγχος ασφαλούς λήψης ρυθμίσεων»** εκτελεί ελεγχόμενα:
1. νέο one-time ασφαλή έλεγχο προετοιμασίας,
2. αίτηση για one-time ticket λήψης,
3. λήψη μόνο του επαληθευμένου managed `.msh`,
4. έλεγχο SHA-256, μεγέθους, απαιτούμενων πεδίων, WSS και του opaque managed node label,
5. προσωρινή εγγραφή με permissions `0600`, επανέλεγχο από δίσκο και άμεση διαγραφή.

Το `.msh` **δεν παραμένει** στο `/data` ή `/tmp` μετά το test. Δεν κατεβαίνει, δεν γίνεται chmod και δεν εκτελείται MeshAgent. Δεν ενεργοποιείται απομακρυσμένη πρόσβαση.
