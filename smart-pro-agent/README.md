# Smart Pro System - Remote Support 2.5.0

Πρώτη ελεγχόμενη managed runtime δοκιμή. Δεν είναι ακόμη η τελική production συνεδρία.

Η σύνδεση μπορεί να ξεκινήσει μόνο μετά από διπλή έγκριση: Smart Pro + πελάτης, και δεύτερη πρόσφατη έγκριση έναρξης από Smart Pro. Η δοκιμή τερματίζεται αυτόματα το αργότερο σε 60 δευτερόλεπτα και δεν εγκαθιστά μόνιμη υπηρεσία.
