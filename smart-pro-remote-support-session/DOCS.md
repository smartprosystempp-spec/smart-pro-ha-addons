# Οδηγίες — Προσωρινή Συνεδρία 0.2.0

## Σκοπός αυτής της έκδοσης
Η 0.2.0 ελέγχει μόνο ότι ένα Home Assistant OS / Green μπορεί να επικοινωνήσει με ασφάλεια με τον Smart Pro Remote Session Broker και να επικυρώσει έναν προσωρινό κωδικό.

## Διαμόρφωση
Στην καρτέλα **Διαμόρφωση** υπάρχουν δύο πεδία:

- **Endpoint επικύρωσης**: προρυθμισμένο στο Smart Pro System. Δεν χρειάζεται αλλαγή στο κανονικό QA.
- **Προσωρινός κωδικός συνεδρίας**: ο κωδικός `SP-XXXX-XXXX` που δημιουργεί ο Admin από το WordPress → Remote Sessions.

Ο κωδικός εμφανίζεται ως password field στο Home Assistant UI. Για αυτή τη development έκδοση αποθηκεύεται προσωρινά στις επιλογές της εφαρμογής και πρέπει να καθαρίζεται μετά το QA.

## QA 0.2.0
1. Δημιουργήστε νέο κωδικό στον Broker.
2. Βάλτε τον κωδικό στη Διαμόρφωση της εφαρμογής και αποθηκεύστε.
3. Πατήστε **Έναρξη**.
4. Στο log πρέπει να εμφανιστεί `ΕΠΙΤΥΧΙΑ: Ο προσωρινός κωδικός είναι έγκυρος.`
5. Στον Broker το `Validations` πρέπει να αυξηθεί κατά 1.
6. Ανακαλέστε τον ίδιο κωδικό στον Broker.
7. Ξεκινήστε ξανά την εφαρμογή. Το log πρέπει να εμφανίσει ότι ο κωδικός έχει ανακληθεί.
8. Μετά τη δοκιμή καθαρίστε το πεδίο του κωδικού.

## Σημαντικό
Η 0.2.0 δεν δημιουργεί πραγματική απομακρυσμένη σύνδεση. Το επόμενο security checkpoint θα αφορά το bootstrap και θα γίνει μόνο μετά την επιτυχή ολοκλήρωση αυτού του QA.
