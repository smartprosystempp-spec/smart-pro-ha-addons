# Οδηγίες — Προσωρινή Συνεδρία 0.1.0

## Τι είναι
Εναλλακτική διαδρομή που σχεδιάζεται για εφάπαξ πελάτη ο οποίος δεν διαθέτει κατάλληλο υπολογιστή για την προσωρινή εφαρμογή Smart Pro Remote Support.

## Τι κάνει η 0.1.0
Η 0.1.0 είναι **foundation / preview**. Αν πατήσετε «Έναρξη», εμφανίζει μόνο ενημερωτικό log και τερματίζεται. Δεν πραγματοποιεί σύνδεση, δεν κατεβάζει agent και δεν αφήνει μόνιμη πρόσβαση.

## Γιατί είναι `manual_only`
Η προσωρινή συνεδρία δεν πρέπει να ξεκινά αυτόματα μετά από επανεκκίνηση του Home Assistant. Η τελική έκδοση θα παραμείνει χειροκίνητης εκκίνησης και θα σχεδιαστεί ώστε να κλείνει καθαρά μετά τη συνεδρία.

## Τι θα προστεθεί αργότερα
- Ασφαλής προσωρινή διαμόρφωση συνεδρίας.
- Πραγματικός Smart Pro Remote Support agent για τη σωστή αρχιτεκτονική.
- Έλεγχος ακεραιότητας του downloaded agent.
- Καθαρά ελληνικά status/log messages.
- Διαδικασία τερματισμού και αφαίρεσης μετά τη συνεδρία.
- Τεκμηρίωση και screenshots για τον τελικό PDF οδηγό.

## Σημαντικό
Μην χρησιμοποιείτε αυτή την preview έκδοση για πραγματική συνεδρία πελάτη.
