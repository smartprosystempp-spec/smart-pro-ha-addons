# Smart Pro System - Remote Support 2.3.0

Η 2.3.0 προσθέτει μόνο ασφαλή λήψη και επαλήθευση του προγράμματος σύνδεσης.

Η ροή της δοκιμής είναι:
1. επιβεβαίωση της εγκατάστασης,
2. νέα ασφαλής λήψη/έλεγχος των ρυθμίσεων,
3. one-time λήψη του σωστού προγράμματος για την αρχιτεκτονική,
4. έλεγχος ELF64, μεγέθους και SHA-256,
5. προσωρινή εγγραφή με δικαιώματα 0600, δεύτερος τοπικός έλεγχος και άμεση διαγραφή.

Δεν γίνεται εκτέλεση, εγκατάσταση service ή απομακρυσμένη πρόσβαση.
